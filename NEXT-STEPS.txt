DeepSeek Harness — 接下来做什么
================================================================

安装完之后的四步。这份文件就放在安装包文件夹里（和 install.cmd、README 同一层），
随时可以打开看，不需要记住任何命令。


----------------------------------------------------------------
1) 打开
----------------------------------------------------------------

双击桌面上的「DeepSeek Harness」。

它会先在后台把服务跑起来，然后自动打开浏览器进入 DSH 界面。
第一次要等几秒。

    · 任务栏上那个最小化的「DeepSeek Harness」窗口就是服务本身
    · 关掉那个窗口 = 停止 DSH
    · 运行日志在 %LOCALAPPDATA%\DSH\dsh-web.log
    · 启动时每 10 秒报一次进度；浏览器没自动弹出时，窗口里会印出完整网址
      （带 token 的那串），复制到浏览器就行
    · 已经开着服务时再双击图标，它会直接把你送回已经开着的界面


----------------------------------------------------------------
2) 接一个模型（第一次打开必做，最容易卡在这里）
----------------------------------------------------------------

浏览器里会弹出「接入模型提供方」窗口，要你填 API 密钥。

「选择模型提供方」保持默认的 DeepSeek 不动，只需要把密钥粘进「API 密钥」框。
密钥要去 DeepSeek 开放平台申请：

    1. 打开   https://platform.deepseek.com/   注册 / 登录
    2. 左侧「充值」—— 账户没钱会直接报「余额不足」，先充最小额度
    3. 左侧「API keys」→「创建 API key」
    4. 复制那串 sk- 开头的密钥（只显示这一次，关掉就看不到了）
    5. 回到 DSH，粘进「API 密钥」框，点「接入并继续」

⚠ 粘贴后检查一下：前后不能有多余的空格或换行，否则会被拒。

完整的图文步骤、报错对照表（401 / 余额不足 / 密钥格式错误 / 连不上）见：

    MODEL-SETUP.txt      ← 同一个文件夹里


----------------------------------------------------------------
3) 选一个「工作区」
----------------------------------------------------------------

接完模型会发现输入框还是灰的 —— 因为还没选工作区。

    · 点「选择工作区」，新建一个目录当工作区，名字就叫 workspace，比如 D:\workspace
    · 选好之后输入框才会亮

建议目录名统一用 workspace（短、全英文最省事）。文献放进去或放别处都行 ——
放别处的话，入库时把完整路径告诉它即可。知识库默认在工作区目录下工作。


----------------------------------------------------------------
4) 把论文加进知识库
----------------------------------------------------------------

新建一个会话，直接说人话就行：

    把 D:\我的论文 里的 PDF 都加进知识库
    把 Zotero 文件夹入库                  （用 Zotero 管理文献的话，这一句就够了）

然后就可以提问了：

    我库里关于 XXX 的文献怎么说？
    XXX 跟 YYY 有什么关系？              ← XXX / YYY 换成你自己的主题

它会带着文献出处（作者 / 年份 / 期刊 / DOI）回答你。

（如果你安装时选了不装 kb-rag，那第 3、4 节用不上：选个工作区就能正常聊天。
  想把知识库加上，重新双击一次 install.cmd，在第 3 步直接回车就行。）


----------------------------------------------------------------
以后怎么更新
----------------------------------------------------------------

重新双击一次本文件夹里的 install.cmd 即可。

所以请保留这个解压出来的文件夹。它会自动检查 DSH 和插件有没有新版本：
有就升级，没有就跳过，已经装好的东西不会重复下载。

（如果你是用 npx 装的，更新就是再执行一次 npx dsh-oneclick。）


----------------------------------------------------------------
出问题了怎么办
----------------------------------------------------------------

1. 先看安装窗口里红色的 [失败] 行
2. 多数情况直接再双击一次 install.cmd 就好了（网络抖动、杀软误拦很常见，
   已经装好的部分会自动跳过）
3. 完整日志在这里，出问题时把最新的那份发给维护者：

       %LOCALAPPDATA%\DSH一键装\日志\

4. 装之前那份说明（这个包干什么、会不会偷偷干别的）：

       GETTING-STARTED.txt
