DSH 一键装 —— 官方 DeepSeek Harness 网页版（kb-rag 文献知识库可选）  新手安装说明
================================================================

你要做的只有一件事：双击本文件夹里的「install.cmd」

它会自动帮你装好：
    1. Node.js 运行时        DSH 要用的，机器上没有才装
    2. 官方 DSH              DeepSeek Harness 命令行工具（含网页界面）
    3. 桌面快捷方式           以后双击图标就能打开 DSH 网页界面（用官方图标）

下面这三样是「知识库」（kb-rag 插件）用的。kb-rag 是这个安装器作者的另一个开源项目，
所以会被推荐；但装不装完全由你定，不装也没有任何损失 —— 安装时会问你一句：
回车＝装（默认建议），回答 n ＝这次只装官方 DSH web，以后想加再重跑一次就行。
    4. kb-rag                本地文献知识库插件（让它读你的论文并带引用回答）
    5. Python 运行环境        插件干活要用的，没装过它会自动装
    6. 检索模型               基础模型 95MB；精排模型 1.1GB（也会问你一句）

    时间：约 8-15 分钟（主要看网速）
    下载：约 0.5 GB（不用精排模型）～ 1.6 GB（用精排模型）
    磁盘：装完约 4 GB，请保证 C 盘至少剩 8 GB


----------------------------------------------------------------
第 0 步：先把压缩包「解压」出来（最容易卡在这）
----------------------------------------------------------------

    · 右键那个 .zip 文件 → 选「全部解压缩…」，解压到一个空间充足的文件夹
      （例如 D:\dsh-oneclick）
    · 不要在压缩包窗口里直接双击 install.cmd。Windows 会把 zip 当文件夹打开，
      但那样并没有真的解压，脚本会报「找不到 tools\install.ps1」。
    · 也不要只把 install.cmd 一个文件拖出来 —— 它必须和 tools\ 文件夹待在一起。
    · 解压完，进到那个文件夹里，再双击 install.cmd。

解压到哪都行（中文名、带空格都测过，没问题）；但别放在 U 盘、网络盘或网盘同步目录里，
装到一半拔盘或掉线会前功尽弃。


----------------------------------------------------------------
第一步：双击「install.cmd」
----------------------------------------------------------------

如果 Windows 弹出蓝色提示「Windows 已保护你的电脑」：
    点「更多信息」→「仍要运行」。
    这是因为脚本从网上下载而来，属于正常现象。

窗口看起来「卡住」不动了？先按一下回车：
    多半是不小心点到了窗口，Windows 控制台进入了「选择文本」状态 ——
    程序其实还在跑，按回车（或 Esc）就恢复了。这是最常见的一类「卡死」。

不需要管理员权限：
    直接双击就行。别用「以管理员身份运行」—— 如果你平时用另一个账户登录这台电脑，
    那样会把东西装到管理员账户下，你自己的桌面上反而看不到图标。

过程中会问你两个问题（都直接按回车＝用默认值，最省事）：
    「是否安装 kb-rag 文献知识库插件？（作者的另一个开源项目，推荐但可选：回车＝装，n ＝不装）」
    「现在就把精排模型也下载好吗？（回车＝下载，输入 n ＝以后再说）」
    两个都建议按回车。不装插件就没有知识库功能；不装精排模型（约 1.1GB）的后果是：
       那约 1.2GB 要等第一次检索时才下 —— 在会话里干等，网络受限还会失败；
       而且精排用不上之后，引擎不再判断「你库里到底有没有这个内容」：
       问库外问题不会提示「无关」，只给一堆分数，排序质量也明显下降。

窗口里的 [完成] / [跳过] / [失败] 都是中文说明，看得懂就行。
中途请不要关窗口。装完会打印一张结果表。


----------------------------------------------------------------
第二步：打开 DSH，接一个模型（关键一步，别慌）
----------------------------------------------------------------

双击桌面上的「DeepSeek Harness」。

    它会做两件事：先在后台把 DSH 服务跑起来（任务栏会出现一个最小化的
    「DeepSeek Harness」窗口，那就是服务本身），然后自动打开浏览器进入 DSH 界面。

    启动时它会每 10 秒报一次进度。万一浏览器没自动弹出，窗口里会印出完整网址
    （带 token 的那串），复制到浏览器地址栏就能进 —— 别自己敲 127.0.0.1:3080，
    那个不带 token 的地址进不去。

    第一次启动要等几秒。浏览器里会弹两个窗口：

  ① 【内测声明】 —— 讲软件还在测试阶段，点「继续」。
  ② 【接入模型提供方】 —— 要你填「API 密钥」。

DSH 本身不会思考，真正回答问题的是模型服务，所以必须给它一把钥匙。
这把钥匙要去 DeepSeek 开放平台申请（免费注册，但要充值才能调用）：

    1. 打开   https://platform.deepseek.com/   注册 / 登录
    2. 左侧「充值」——账户没钱会直接报「余额不足」，先充最小额度
    3. 左侧「API keys」→「创建 API key」
    4. 复制那串 sk- 开头的密钥（只显示这一次！）
    5. 回到 DSH 网页，粘进「API 密钥」框，点「接入并继续」

⚠️ 详细图文步骤、报错对照表，见本文件夹里的：

      MODEL-SETUP.txt

※ 用完想关掉 DSH：关掉任务栏那个最小化的「DeepSeek Harness」窗口即可。
   下次再双击桌面图标，它会重新起来并自动打开浏览器。

第三步：选一个「工作区」，否则输入框是灰的
----------------------------------------------------------------

接完模型还会发现输入框不能打字 —— 因为还没选工作区。

    · 点「选择工作区」，新建一个目录当工作区，名字就叫 workspace（比如 D:\workspace）
    · 选好之后输入框才会亮

建议目录名统一用 workspace：短、全英文，不会踩到符号和编码的坑。你的文献可以直接放进
这个目录，也可以放在别处、入库时把路径告诉它。知识库默认就在工作区目录下工作。


----------------------------------------------------------------
第四步：把你的论文加进知识库
----------------------------------------------------------------

在 DSH 里新建一个会话，直接说人话就行，例如：

    「把 D:\我的论文 里的 PDF 都加进知识库」
    「把 Zotero 文件夹入库」（用 Zotero 管理文献的话，这一句就够了）

然后就可以提问了，例如：

    「我库里关于 XXX 的文献怎么说？」
    「XXX 跟 YYY 有什么关系？」            ← XXX / YYY 换成你自己的主题

它会带着文献出处（作者 / 年份 / 期刊 / DOI）回答你。


----------------------------------------------------------------
以后怎么更新
----------------------------------------------------------------

再双击一次「install.cmd」就行 —— 就是本文件夹里那个。

它会自动检查 DSH 和插件有没有新版本：有新版本就升级，没有就跳过。
已经装好的东西不会重复下载，所以第二次运行通常很快。


----------------------------------------------------------------
装不上怎么办
----------------------------------------------------------------

1) 先看窗口里红色的 [失败] 行，它写了是哪一步出的问题。
2) 多数情况直接再双击一次 install.cmd 就好了 —— 这类失败基本是网络抖动或杀软误拦，
   第二次运行会自动跳过已经装好的部分（用户实测有效，先试这个）。
3) 完整日志在这里，把日志发给维护者最快：
       %LOCALAPPDATA%\DSH一键装\日志\
4) 常见情况：

   一直卡在下载
       网络问题。关掉重新双击一次即可 —— 已经下完的文件会自动跳过（没下完的会重下一遍）。
       如果反复失败：手动把 Node.js 压缩包（node-v24.21.0-win-x64.zip，见 payload\README.txt）
       下载好放进本文件夹的 payload\ 目录，再双击脚本，它会直接用本地文件、不再联网。
       （payload\ 只认这个 Node 压缩包；DSH 本体和插件是走 npm 的，放进去没用。）

   提示 C 盘空间不足
       先清理到 8GB 以上再跑。

   提示「装完了但还是找不到 Python」
       官方 Python 安装包没下成功，或者静默安装没成功。手动装一个 Python 3.9+
       （https://www.python.org/downloads/ ），装完重新双击脚本，剩下的步骤会自动继续。

   提示没有 Python
       脚本会自动装官方 Python（装到当前用户，不需要管理员权限，不会污染系统环境）。


----------------------------------------------------------------
只想检查、不想改动
----------------------------------------------------------------

体检（只报告现状，不装任何东西）：
    powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 -CheckOnly

自检下载通道（只下载和校验，不安装）：
    powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 -SelfTest

演练（只打印将要做什么，不下载不安装）：
    powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 -DryRun

这个包里有什么
----------------------------------------------------------------

install.cmd          你要双击的就是它
GETTING-STARTED.txt             本文件（装之前看）
MODEL-SETUP.txt     装完之后看：第一次打开 DSH 要填 API Key，怎么弄
NEXT-STEPS.txt      装完之后四步：打开 / 接模型 / 选工作区 / 用知识库
tools\install.ps1        真正的安装逻辑（中文注释，想看可以看）
tools\dsh-web.ps1        桌面快捷方式背后的启动器（启动 dsh web 并打开浏览器）

sha256.txt               每个文件的校验值，可用于核对文件有没有被改过

可选：payload\ 目录里可以放一个 node-v24.21.0-win-x64.zip（官方 Node.js 压缩包），
机器上没有 Node 时脚本就直接用它，不再联网下载。详见该目录里的 README.txt。


----------------------------------------------------------------
它会不会偷偷干别的
----------------------------------------------------------------

不会。脚本做的事都在窗口里一行行打印出来，而且：

    - 不装任何后台服务，不设置开机自启
    - 不需要管理员权限（Node.js / DSH / Python 都装在当前用户下）
    - 走的是官方渠道：Node.js 用官方 SHASUMS256.txt 里的哈希核对，
      DSH 和插件走 npm registry（国内默认换成 npmmirror 镜像加速）
    - 本脚本下载的文件都核对官方校验值：Node.js 用官方 SHASUMS256.txt 的 sha256，
      Python 安装包用 python.org 发布的 sha256（另有官方 MD5 兜底）；
      校验不过就换下一个通道重下

它只往这几个地方写东西：
    - %LOCALAPPDATA%\DSH           便携版 Node.js（机器上原本没有才装）、启动器、图标
    - %USERPROFILE%\.dsh           DSH 自己的配置和数据（与官方一致）
    - npm 全局目录（%APPDATA%\npm）  dsh 和 pnpm 这两个命令行工具
    - %LOCALAPPDATA%\DSH一键装      本脚本的下载缓存和日志
    - 桌面快捷方式

注意：本包装的就是**官方的 DSH web**：`@deepseek-ai/dsh`（DeepSeek 官方发布的
命令行工具）自带的网页界面，用官方推荐的 `dsh web` 方式启动，数据目录也用官方
默认的 %USERPROFILE%\.dsh。


----------------------------------------------------------------
关于图标
----------------------------------------------------------------

桌面快捷方式用的是 **DeepSeek 官方图标**（取自官网 favicon，品牌蓝 #4D6BFE），
已重打成 16~256 多种尺寸。详细来源见 assets\ICON-SOURCE.txt。

说明：用这个图标只是让人一眼看出"它启动的是 DeepSeek Harness"，
本安装包本身是一份第三方辅助脚本，不是 DeepSeek 官方发布的。
