DSH 第一次打开，蹦出来一个要填 API Key 的窗口 —— 怎么办
================================================================

先讲清楚这是怎么回事，你就不慌了：

    DSH 是个「壳」，它自己不会思考。真正回答问题的是「模型服务」
    （DeepSeek 官方的服务器）。这个窗口就是让你把「模型服务的钥匙」
    ——也就是 API Key——填进去，填完 DSH 才能干活。

    这把钥匙要去 DeepSeek 开放平台申请，下面是完整步骤。


----------------------------------------------------------------
一、你现在看到的界面
----------------------------------------------------------------

在浏览器里打开 DSH 之后，会依次弹出两个窗口：

  ① 【内测声明】
     内容大意是：这个软件还在面向开发者测试，会持续迭代。
     →  点「继续」。

  ② 【接入模型提供方】   ←←←  卡住你的就是这一个

     大致长这样（示意）：

     ┌────────────────────────────────────────────┐
     │  接入模型提供方                              │
     │                                            │
     │  选择提供方并填写 API Key，DSH 会自动启用该    │
     │  提供方的内置模型目录。之后可在「设置 → 模型」  │
     │  中添加更多提供方。                          │
     │                                            │
     │  选择模型提供方   [ DeepSeek           v ]  │
     │                    （模型厂商）              │
     │                                            │
     │  API 密钥         [ 输入 API 密钥        ]  │
     │                                            │
     │              [ 稍后配置 ]  [ 接入并继续 ]    │
     └────────────────────────────────────────────┘

     默认选中的就是 DeepSeek，保持不动即可。
     你要做的事只有一件：把一串 sk- 开头的密钥粘进「API 密钥」框。

     下拉框里其实还有很多选择（都按类别分好了）：
        模型厂商     ：DeepSeek / OpenAI / Anthropic / Google Gemini / xAI /
                       Moonshot 即 Kimi / MiniMax / 智谱 GLM / Mistral AI
        模型聚合平台 ：OpenRouter
        推理服务平台 ：Groq / Together AI
     国内用户选 DeepSeek 最省事（不用额外配代理）。


----------------------------------------------------------------
二、第一步：去申请一把钥匙（约 3 分钟）
----------------------------------------------------------------

1. 浏览器打开 DeepSeek 开放平台：

       https://platform.deepseek.com/

   注意：这是「开放平台」，和你平时聊天用的 deepseek.com 不是一个站，
   但用同一个手机号 / 微信就能登录。

2. 注册或登录。

3. 【这一步最容易漏】先充值。
   开放平台的 API 是按用量扣费的，账户没钱会直接报错（余额不足）。
   左侧菜单里找「充值」，充最小额度就能用很久——日常问答一次也就几分钱。

4. 左侧菜单点「API keys」，然后点「创建 API key」。
   直达链接：

       https://platform.deepseek.com/api_keys

5. 给它起个名字（随便填，例如 dsh），确认创建。

6. 屏幕上会显示一串以 sk- 开头的密钥。**立刻复制它。**

   ⚠️ 这串东西只完整显示这一次，关掉窗口就再也看不到了
      （真丢了只能在平台上删掉重建一个）。


----------------------------------------------------------------
三、第二步：粘回 DSH
----------------------------------------------------------------

1. 回到【接入模型提供方】窗口，「选择模型提供方」保持 DeepSeek 不动。

2. 在「API 密钥」框里按 Ctrl+V 粘贴。

   ⚠️ 粘完检查一下：开头和结尾都不能有多余的空格或换行。
      从网页复制很容易多带一个空格，界面会直接报「该 API 密钥格式错误，请检查。」

3. 点「接入并继续」。

成功的话窗口关闭，进入 DSH 主界面。模型立刻可用，不需要重启。


----------------------------------------------------------------
四、第三步：还要选一个「工作区」，否则输入框是灰的
----------------------------------------------------------------

这是新手的第二个坑，官方文档原话是：选中工作区前，会话输入框不可用。

    · 点界面上的「选择工作区」（或「添加工作区」）
    · 新建一个目录当工作区，名字就叫 workspace，比如 D:\workspace
    · 选好之后，下面的输入框才会亮起来

建议目录名统一用 workspace：短、全英文，不会踩到符号和编码的坑。知识库插件默认就在
这个目录下工作 —— 库文件写在它下面的 .kb 里。你的文献可以直接放进 workspace，也可以
放在别的盘上、入库时把完整路径告诉它，两种都行。

选之前先看一眼这块盘还剩多少空间，这一步不少人装完才后悔：

    · 知识库就是所选目录下的一个 .kb 文件夹，会随文献量一直长。
      实测：316 篇的库约 100MB（平均每篇约 0.33MB，含正文与向量）；
      1000 篇大约 300MB。再加上会话产物和以后导出的文件，
      建议所选磁盘至少留 10GB 空闲。
    · 优先选 D:、E: 这类数据盘。放 C: 系统盘也能用，但安装本身还要占掉约 4GB
      （Python、torch、命令行工具，以及两个检索模型），C: 太满会拖慢整机。
    · 别放在 OneDrive、坚果云、百度网盘这类同步目录里：索引文件会被反复上传下载，
      还可能被同步程序锁住，检索就会报错。
    · 别放在网络盘、U 盘、移动硬盘上：一掉线或拔盘，当前会话和索引就用不了了。
    · 路径尽量短、别用特殊符号。中文路径没问题（旧版本的编码坑已经修掉），
      但纯英文路径最省事。

    一个容易误会的点：换工作区只能挪动「文献库 + 会话产物」。
    两个检索模型（约 1.2GB）固定在 C:\Users\<你的用户名>\.cache\huggingface，
    不跟着工作区走 —— 所以 C 盘本来就要留出这部分。

    想换随时能换：点「添加工作区」选一个新目录即可。旧知识库留在原目录里，
    不会自动搬过去；需要的话在新工作区里重新入库一次就行。


----------------------------------------------------------------
五、第四步：试一句，确认通了
----------------------------------------------------------------

在输入框里发一句最普通的：

    你好，请用一句话介绍你自己

    · 有回复  →  全部搞定
    · 报错    →  看下一节对照表

确认通了以后，就可以试知识库了。两种入库方式，看你文献是怎么存的：

    把 D:\我的论文 里的 PDF 都加进知识库        ← 手上是一堆 PDF：换成你自己的文献目录
    把 Zotero 文件夹入库                        ← 用 Zotero 管理文献：这一句就够了

入库完再问它（XXX 换成你自己的主题）：

    我库里关于 XXX 的文献怎么说？

（文献目录和工作区可以是两个地方：上面那句给的是完整路径，放哪儿都认。
  没用 Zotero 就不要发那句，直接说 PDF 文件夹的路径即可。）

----------------------------------------------------------------
七、常见追问
----------------------------------------------------------------

问：一定要用 DeepSeek 吗？
答：不一定。那个下拉框里还能选 OpenAI、Anthropic、Google Gemini、xAI、
    Kimi（Moonshot）、MiniMax、智谱 GLM、Mistral，聚合平台 OpenRouter，
    推理平台 Groq / Together。
    国内用户选 DeepSeek 最省事，因为不用额外弄代理。
    以后想加别的：设置 → 模型 → 添加提供方。

问：填错了 / 想换一个密钥？
答：设置 → 模型 → 找到 DeepSeek 那一行 → 重新填「API 密钥」→ 应用。
    那一行旁边有状态点：绿点＝已配置，红点＝缺失。

问：密钥会不会被写进什么文件里泄露？
答：它保存在你本机的凭据库里：

        %USERPROFILE%\.dsh\.credentials.yaml

    同目录下的 settings.yaml 只存引用名（DEEPSEEK_API_KEY），不存密钥本身。
    别把这个文件发给别人就行。
    （在文件管理器地址栏输入 %USERPROFILE%\.dsh 就能打开那个目录。）

问：大概要花多少钱？
答：按用量（token）计费，官方价目表：
        https://api-docs.deepseek.com/zh-cn/quick_start/pricing
    便宜的 flash 模型很省钱，pro 模型贵一些。
    想省钱在模型选择里用 flash 就行。

问：界面上的模型名和文档对不上？
答：官方现在的模型名是 deepseek-flash 和 deepseek-v4-pro。
    界面上可能显示 deepseek-v4-flash 之类的旧名字，旧名仍然可用
    （由新版模型提供服务，按 flash 价格计费）。

问：点了「稍后配置」会怎样？
答：能进主界面，但没接模型，一发消息就会提示缺密钥。
    之后随时可以补：设置 → 模型 → 填密钥。

问：公司 / 学校网络连不上怎么办？
答：DSH 支持走代理。先确认系统代理能用，再重启 DSH。
    也可以看看官方「网络代理」文档。

问：我怎么知道密钥配好了？
答：设置 → 模型 里 DeepSeek 那一行显示绿点「API 密钥已配置」；
    或者直接发一句话试试，有回复就是通了。
